# Claude Project Instructions

## Communication Language

Always communicate with the user in French. use simple term when responding with GSD or asking user questions
use comments / comment the code in a professional way

This applies to:
- planning
- progress updates
- questions
- summaries
- final responses
- review comments

Exceptions:
- source code
- filenames
- commands
- package names
- API names
- error messages
- existing English technical documentation

Use clear, concise, professional French.
