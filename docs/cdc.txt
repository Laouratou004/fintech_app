1. Contexte stratégique et économique
Les transferts d’argent de la diaspora constituent l’un des piliers économiques majeurs de nombreux pays africains.
En République de Guinée, les flux financiers provenant :
1. de France ;
2. des États-Unis ;
3. du Canada ;
4. de Belgique ;
5. d’Allemagne ;
6. des pays du Golfe ;
7. d’Afrique centrale ;
représentent plusieurs centaines de millions de dollars chaque année.
Ces transferts alimentent :
1. les dépenses familiales ;
2. les investissements ;
3. l’immobilier ;
4. les études ;
5. les soins médicaux ;
6. les PME locales.
Dans un contexte de digitalisation financière, les applications fintech modernes doivent :
1. respecter les réglementations de la Banque Centrale de la République de Guinée (BCRG) ;
2. intégrer les taux de change officiels ;
3. gérer les frais de transfert ;
4. assurer la sécurité des transactions ;
5. lutter contre le blanchiment d’argent (AML/KYC).

8. Slice Redux
store/transferSlice.js
import { createSlice } from "@reduxjs/toolkit";

const initialState = {

 transfers: [],

 exchangeRate: 9500,
};

const transferSlice = createSlice({

 name: "transfers",

 initialState,

 reducers: {

   addTransfer: (state, action) => {

     state.transfers.push(action.payload);
   },

   updateRate: (state, action) => {

     state.exchangeRate = action.payload;
   },
 },
});

export const {
 addTransfer,
 updateRate,
} = transferSlice.actions;

export default transferSlice.reducer;

11. Écran principal de transfert
screens/TransferScreen.js
import React, {
 useState,
} from "react";

import {
 View,
 Text,
 TextInput,
 Button,
 StyleSheet,
} from "react-native";

import {
 useDispatch,
 useSelector,
} from "react-redux";

import {
 addTransfer,
} from "../store/transferSlice";

import {
 calculateFees,
} from "../utils/feeUtils";

const TransferScreen = () => {

 const dispatch = useDispatch();

 const rate = useSelector(
   state => state.transfers.exchangeRate
 );

 const [amount, setAmount] = useState("");

 const [receiver, setReceiver] =
   useState("");

 const submitTransfer = () => {

   const fees = calculateFees(
     Number(amount)
   );

   const converted =
     Number(amount) * rate;

   dispatch(
     addTransfer({

       id: Date.now(),

       receiver,

       amount,

       fees,

       converted,
     })
   );
 };

 return (

   <View style={styles.container}>

     <Text style={styles.title}>
       Transfert Diaspora Guinée
     </Text>

     <TextInput
       placeholder="Nom du bénéficiaire"
       value={receiver}
       onChangeText={setReceiver}
       style={styles.input}
     />

     <TextInput
       placeholder="Montant en EUR"
       keyboardType="numeric"
       value={amount}
       onChangeText={setAmount}
       style={styles.input}
     />

     <Button
       title="Envoyer"
       onPress={submitTransfer}
     />

   </View>
 );
};

const styles = StyleSheet.create({

 container: {
   flex: 1,
   padding: 20,
   justifyContent: "center",
 },

 title: {
   fontSize: 24,
   fontWeight: "bold",
   marginBottom: 20,
   textAlign: "center",
 },

 input: {
   borderWidth: 1,
   borderColor: "#ccc",
   padding: 12,
   marginBottom: 15,
   borderRadius: 10,
 },
});

export default TransferScreen;
 
12. FlatList — Historique des transferts
screens/HistoryScreen.js
import React from "react";

import {
 View,
 Text,
 FlatList,
 StyleSheet,
} from "react-native";

import { useSelector }
from "react-redux";

const HistoryScreen = () => {

 const transfers = useSelector(
   state => state.transfers.transfers
 );

 return (

   <FlatList

     data={transfers}

     keyExtractor={(item) =>
       item.id.toString()
     }

     renderItem={({ item }) => (

       <View style={styles.card}>

         <Text>
           Bénéficiaire :
           {item.receiver}
         </Text>

         <Text>
           Montant :
           {item.amount} €
         </Text>

         <Text>
           Frais :
           {item.fees} €
         </Text>

         <Text>
           Reçu :
           {item.converted} GNF
         </Text>

       </View>
     )}
   />
 );
};

const styles = StyleSheet.create({

 card: {
   backgroundColor: "#fff",
   padding: 15,
   margin: 10,
   borderRadius: 10,
   elevation: 4,
 },
});

export default HistoryScreen;
